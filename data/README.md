# Data Directory

This directory contains runtime databases, SIEM log streams, raw PCAP captures, and processed sequence datasets.

## Directory Structure
- `raw/`: Raw packet captures (`.pcap`) from lab environments.
- `processed/`: Serialized 10x60s sequence matrices.
- `pcaps/`: Reproducible lab PCAP files (`lab_benign.pcap`, `lab_fast_scan.pcap`, `lab_stealth_scan.pcap`).
- `nids.db`: SQLite database running in WAL mode (alerts, devices, metrics).
- `siem_alerts.jsonl`: SIEM-compatible JSON-Lines alert stream (Elastic / Splunk ECS schema).
- `evaluation_report.json`: Metrics report generated by `scripts/run_evaluation.py`.
